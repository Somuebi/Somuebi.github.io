Rate My Dorm

An interactive web platform to help WPI students find the on-campus dorm that best fits their needs.

Tech Stack

  • HTML
  • CSS
  • JavaScript
  • Project Management
  • Jinja
  • Figma
  • Python
  • MongoDB
  • FastAPI

Chef's Note

Using Figma, FastAPI, and MongoDB Atlas, I collaborated with a team of developers to create Rate My Dorm, a web-based platform that helps WPI students make informed housing decisions based on factors like room size, proximity to dining and academic buildings, and available amenities. Throughout the project, we designed an interactive UI, built a RESTful backend, and integrated a database for user-submitted reviews—gaining hands-on experience coordinating a five-person team and delivering a full-stack product that ultimately won Best Community Hack at GoatHacks 2026.
