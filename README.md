# Mmesoma Onwusika | Portfolio

Personal portfolio site showcasing my projects, skills, and background as a software engineer.

**Live site:** [somuebi.github.io](https://somuebi.github.io/)

## About

This is a hand-built, static portfolio with no frameworks or build step. I wrote it from scratch in HTML, CSS, and JavaScript to keep it fast, lightweight, and easy to maintain, and to practice designing and building an interface end to end.

The site is organized around a few goals:

- **Clarity:** easy to navigate, with the important things visible quickly
- **Usability:** readable typography, consistent layout, and responsive design
- **Simplicity:** minimal dependencies and no unnecessary complexity

## Running Locally

No installation or build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Somuebi/Somuebi.github.io.git
   cd Somuebi.github.io
   ```
2. Serve it with any static file server. For example, using Python:
   ```bash
   python3 -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.

You can also open `index.html` directly in a browser, though some features work best when served over HTTP.

## Deployment

The site is deployed with GitHub Pages from the `main` branch. Pushing changes to `main` updates the live site automatically.
